# Into-the-Dead-Our-Darkest-Days-VR
VR Mod for Into the Dead: Our Darkest Days

INTO THE DEAD: OUR DARKEST DAYS - VR MOD  v0.1.13
==========================================================================
Unity 6000.5.11f1 (IL2CPP, HDRP) + BepInEx 6.0.0-be.788.

1. Copy the unzip over the game's folder folder.
2. Start SteamVR / Quest Link / Virtual Desktop first (it must be the OpenXR runtime), then the game.
4. Settings: BepInEx\config\intothedead.ourdarkestdays.vr.cfg (changes apply live), or the VR settings
   menu in the headset: hold Y + left stick click for 1.7 s.

HOW IT PLAYS
- You stand where the game's camera is: the side-on world is a 3D stage in front of you.
  [View] NormalViewZoom < 1 brings you closer to your character (e.g. 0.6), NormalViewHeightOffset up/down.
- The game's menus and HUD are on a floating screen in front of you. In menus the screen is solid;
  in gameplay it is drawn "added on top" (the black around the HUD is see-through). [UI] Blend.
  If the screen is upside down: [UI] FlipY = Yes (or No).
- Menus: point with the right controller and pull the trigger to click, or use the sticks / A / B.

CONTROLS (the VR controllers are an Xbox controller for the game)

  Left stick ....... left stick              Right stick ...... right stick (in menus: d-pad)
  
  A / B ............ A / B                   X (tap) / Y (tap)  X / Y
  
  Left / right grip  LB / RB                 Left / right trigger LT / RT
  
  Stick clicks ..... L3 / R3                 X + Y together ... Start (pause)
  
  Hold Y ........... Back / View             Hold X ........... d-pad up
  
  Hold LT + left stick = d-pad (up / down / left / right)
  
  Both stick clicks  re-centre the view      Y + left stick click (hold) ... VR settings menu
  
  Change any of it in [Controls].
